رسم مخططات القص والعزم يدوياً

دليل عام لكل أنواع الكمرات والأحمال بطريقة المرونة (Flexibility Method)، ومعه أداة تحل وترسم لك.

١) خطوات الحل بمصفوفة المرونة

  1. درجة اللاتحديد: r = (عدد ردود الأفعال المجهولة) − 2. مثال: عمود ثابت + ساندين مفصلية → A1, M1, A2, A3 = 4 مجاهيل، r = 2.
  2. اختر المجاهيل الزائدة X (r منها، مثل A2 و M1) وأزلها، فتصبح الكمرة محددة (الكمرة الأساسية).
  3. احسب الانتقالات Δi0 عند أماكن المجاهيل بسبب الأحمال الأصلية على الكمرة الأساسية.
  4. احسب معاملات المرونة fij = الانتقال في الموضع i بسبب قوة (أو عزم) قيمته 1 في الموضع j.
  5. معادلة التوافق: الانتقال الحقيقي عند الساند معلوم (غالباً صفر).
    [ f11 f12 ; f21 f22 ] { X1 ; X2 } = { Δ1 − Δ10 ; Δ2 − Δ20 }
  6. الاتزان: ΣFy = 0 و ΣM = 0 تعطيك باقي المجاهيل (A1, M1 ...).
  7. ارسم V ثم M (القواعد في القسم ٣).
